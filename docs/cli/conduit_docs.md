## conduit docs

Generate CLI reference documentation

### Synopsis

Generate Markdown docs for every command plus the FlowDSL grammar reference.

```
conduit docs [flags]
```

### Options

```
  -h, --help         help for docs
  -O, --out string   output directory (default "docs/cli")
```

### Options inherited from parent commands

```
      --config string   path to config file (default "conduit.yaml")
      --no-input        never prompt; fail instead (for CI/agents)
  -o, --output string   output format: table|json|yaml
  -v, --verbose count   increase verbosity (-v, -vv)
```
